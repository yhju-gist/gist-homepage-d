# GIST 대표 홈페이지 D안 (시안)

> GIST 홈페이지 통합 재구축 TF 단과대학 의견으로 공과대학 교학팀이 만든 **화면 시안**입니다.
> 실제 운영 홈페이지가 아닙니다. 내용·사진의 최종 사용은 대외홍보팀 확인 후 결정합니다.

## 바로 보기
- 이 저장소의 **GitHub Pages 주소**로 열면 PC·휴대폰에서 바로 볼 수 있습니다.
- 내려받아 볼 때: `index.html`을 크롬으로 열기 (`img` 폴더와 같은 자리, 인터넷 연결 필요)
- 회의 의견 반영 보고: 주소 뒤에 `#reflect` (줄마다 [그 화면으로]를 누르면 고친 자리로 이동)
- 주소 뒤에 붙여 바로 열기: `#colleges`(대학·학과) `#d-chem`(학과) `#search` `#tutorial` `#story` `#st-0`(소식 글) `#p-4-3-1`(세부페이지) `#guide`(디자인 규칙)

## 내용 고치는 곳 (`src/index_source.html` 안에서 이름으로 찾기)
- `STORIES` G-Story 소식 · `NOTICES` 공지 · `EVENTS` 학사일정 · `COLLEGES` 단과대학·학과 목록
- `DEPT` 학과 소개 · `PBODY` 세부페이지 본문 · `MEGA` 전체 메뉴 · `TOP` 튜토리얼 · `QA` AI 안내 답
- `SIMG` 소식별 사진 · `DPH` 학과별 머리 사진 · `:root` 색·글꼴 값

## 알아둘 점
- 화면 안 '관리자' 편집·저장 기능은 Claude 아티팩트 판에서만 동작합니다. 이 저장소(GitHub Pages)는 **보기 전용**입니다.
- 공개 라이브러리는 버전을 고정해 jsdelivr에서 불러옵니다 (gsap 3.12.5, swiper 11.1.14, fuse.js 7.0.0, lucide 0.453.0, echarts 5.5.1 등).
